# 语音小助手

一个在 Home Assistant 里使用的中文语音控制插件，作为 Conversation Agent 接入 HA 语音助手。

## 安装

HACS 添加自定义仓库 `https://github.com/shaonianzhentan/conversation`，搜索 `语音小助手` 安装，重启 HA 后在集成中添加。

## 配置

添加集成后，在选项中配置以下实体（可选）：

| 配置项 | 说明 |
|---|---|
| 日历 | 用于创建提醒事件 |
| 音乐 | 网易云音乐媒体播放器 |
| 广播 | 通用媒体播放器（播放广播） |
| 小爱音箱 | 小米米家小爱音箱 |
| 小度音箱 | 小度音箱 |

## 支持指令

### 设备控制

- 打开/关闭 `设备名称`
- `区域名`的 `设备名称` 打开/关闭
- 灯光亮度设为 `数字`%
- 灯光调成 `颜色`
- 触发 `自动化/按钮/脚本`
- 激活 `场景名`

### 媒体播放器

- 播放 / 暂停
- 上一曲 / 下一曲
- 声音大一点 / 声音小一点
- 音量设为 `数字`%

### 空调

- `自动/制热/制冷/除湿/送风`模式
- 温度设为 `数字`度
- 湿度设为 `数字`%

### 音乐（网易云）

- 播放每日推荐
- 播放我喜欢的音乐
- 我想听 `歌名` 的歌
- 播放歌单 `歌单名`
- 播放电台 `电台名`
- 播放专辑 `专辑名`
- 随机播放 / 单曲循环 / 列表播放

### 日历提醒

- `时间`提醒我`要做的事`
- 发送日历实体名称查看近期事件

### 小爱音箱

- 小爱`打开卫生间的灯`

### 小度音箱

- 小度`打开卫生间的灯`

### 广播

- 播放广播

## TTS

内置有道词典 TTS，在 HA 语音助手设置中选择 `语音助手TTS` 即可使用。
